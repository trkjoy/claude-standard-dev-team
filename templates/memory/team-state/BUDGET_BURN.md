# BUDGET_BURN — 循环预算消耗记录

> 由自动循环 workflow（如 nightly-audit）在每次运行后由调用方填写。
> 人主导的串行流程无需填写此文件（沿用 RETRY_LOG.md 的轮次记录即可）。
> 追加写入，不覆盖历史记录；每次记录以 `---` 分隔。

---

## 字段说明

| 字段 | 含义 | 示例 |
|------|------|------|
| `循环名称` | workflow 名称或任务标识 | nightly-audit |
| `触发方式` | cron / hook / 人工 | cron |
| `开始时间` | 调用方注入的 ISO 时间戳 | 2026-06-23T02:00:00Z |
| `结束时间` | 调用方注入的 ISO 时间戳 | 2026-06-23T02:18:42Z |
| `实际轮次` | 实际执行的巡检轮次数 | 2 |
| `最大轮次` | 配置的轮次上限 | 3 |
| `Token 耗用` | 实际消耗 token 数；若计量不可得填 N/A | 12800 或 N/A |
| `Token 上限` | 配置的 token 上限；未设置填 N/A | 50000 或 N/A |
| `是否熔断` | true / false | false |
| `熔断原因` | 触发熔断时的原因；未熔断留空 | 连续 2 轮无新增发现 |
| `发现总数` | 本次巡检累积确认的发现条数 | 5 |
| `Blocker 数` | critical + high severity 总数 | 2 |
| `备注` | 其他需要记录的信息（可选） | — |

---

## 记录示例

```
循环名称 : nightly-audit
触发方式 : cron
开始时间 : 2026-06-23T02:00:00Z
结束时间 : 2026-06-23T02:18:42Z
实际轮次 : 2 / 3
Token 耗用: N/A（token 计量待验证，本次降级模式）
Token 上限: N/A
是否熔断 : false
熔断原因 : （未熔断）
发现总数 : 5
Blocker数 : 2（critical=1 / high=1）
备注     : 首次夜间巡检，基线建立
---
```
