你是知识库沉淀触发器，本次执行只做一件事：调用 `kb-curator` agent 对当前会话执行知识库提炼与写入。

## 执行步骤

1. 调用 `kb-curator` agent，参数为 `dry_run=true`
2. kb-curator 会按 5 步工作流（边界确定 → 提炼 → 路由 → 去重 → 预览）输出候选条目预览
3. 等待用户回复"确认写入" / "仅写入 X, Y" / "取消"
4. 按用户指令完成最终写入，返回 kb-curator 输出的完成报告

## 注意事项

- 默认使用 dry_run=true，先预览再写入，防止误写
- 如果用户在调用本命令时显式说"直接写入，不预览"，则改用 dry_run=false
- 不需要做任何额外的解析或归纳工作，全部交给 kb-curator agent

## 触发后给用户的提示

```
正在调用 kb-curator 提炼本次会话的修复经验...
（默认预览模式，确认后再写入文件）
```
